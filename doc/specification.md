製品副題は「Electric Motor Simulation」。内部パッケージ名は `flux_gazer`。JSON形式識別子 `motor_sim.standard_spm` は既存ファイルとの互換性のため維持する。作業ディレクトリ名は製品名とは独立し、本名称変更では変更しない。

## 1. 目的と適用範囲

永久磁石、集中巻線、鉄心を含むモーター断面の静磁界を計算し、ロータ位置・三相電流・進角による磁束経路とトルク参考値の変化を可視化する。

対象機能は標準形状生成、線形物性定義、JSON保存・読込、一次三角形FEM、準静的な位置走査、磁力線・歯Br表示、無次元トルクと履歴グラフ、CSV出力、軸設定、明暗テーマ切替とする。

回転位置はユーザー操作または一定角度刻みの走査で与える。運動方程式を解かず、実回転数、速度応答、負荷追従を表現しない。無次元結果をT、A、Nmとして表示しない。

## 2. 実行環境・起動

確認環境はWindows、Python 3.12、リポジトリ内の `.venv`。GUIはPySide6、描画はMatplotlibを使用する。依存ライブラリの許容範囲は `requirements.txt` を正とし、固定バージョンのロックファイルではない。

|ライブラリ|定義範囲|用途|
|---|---|---|
|NumPy|2.0以上、3未満|配列演算|
|SciPy|1.14以上、2未満|疎行列・LU分解|
|Matplotlib|3.9以上、4未満|磁界・グラフ・要素内補間|
|PySide6|6.7以上、7未満|GUI・ワーカースレッド|
|triangle|20250106以上|境界拘束三角形メッシュ|
|Shapely|2.0以上、3未満|形状生成・領域演算・検査|
|pytest|8以上、10未満|自動検証|

リポジトリ直下で実行する。

```powershell
.\.venv\Scripts\python.exe main.py
# 同等の起動方法
.\.venv\Scripts\python.exe -m flux_gazer
.\run.ps1
```

新規環境ではPythonで `.venv` を作成し、そのPythonを使って `pip install -r requirements.txt` を実行する。アプリ内のimportは `flux_gazer.*` の絶対importを用いる。Windowsでは利用可能なメイリオを読み込む。日本語表示には対応フォントが必要。

|u, v|各歯または磁石の局所径方向・反時計回り接線方向座標|

## 5. 形状生成仕様

### 5.1 初期8P12S形状

|部位|無次元寸法・配置|
|---|---|
|固定子ヨーク|内半径0.85、外半径1.00|
|歯|u=0.64～0.88、v=±0.065、12本、30°間隔、歯0は+x|
|ロータ鉄心|アポセム0.47の正八角形、軸穴半径0.15|
|磁石|8個、45°間隔。底面u=0.47、半幅0.16、高さ0.12、頂点u=0.59|
|コイル片側|u=0.68～0.82、v=0.078～0.12。反対側にも対称配置|
|最小空隙|0.64−0.59=0.05|

歯とヨークの重なりは同一鉄心として形状和を取る。歯先の張り出しはない。磁石断面は平面底面と凸円弧からなる。半幅w、高さhに対し円弧半径R=(w²+h²)/(2h)、円中心u=a+h−R。aは最終アポセム。磁石底面と鉄心の端点を共有する。

輪郭の円・円弧は弦で近似し、磁石中央頂点を必ず含める。同じポリゴンを表示、材料判定、境界拘束メッシュに用いる。CADの厳密円弧ではない。

### 5.2 極数・空隙によるロータ寸法調整

Sによる歯・コイルの接線幅倍率はs=min(1,12/S)。磁石の元半幅・元厚さの倍率はm=min(1,tan(π/P)/tan(π/8))。

元アポセムをa₀=min(apothem,(tooth_inner−0.025)cos(π/P))とする。w₀=magnet_half_width×m、h₀=magnet_height×m。

```
包絡半径 r₀ = max(a₀/cos(π/P), a₀+h₀, sqrt(a₀²+w₀²))
拡大縮小倍率 k = (tooth_inner−air_gap)/r₀
最終寸法 (a,w,h) = k(a₀,w₀,h₀)
```

鉄心外形と磁石を連動拡大縮小するが、軸穴半径は保つ。最終鉄心が軸穴より小さい場合は拒否する。空隙は「回転包絡面と歯先内接円の半径差」であり、各位置の局所ギャップが一定という意味ではない。

### 5.3 標準生成での径の指定

固定子外径Ds、ロータ包絡外径Dr、空隙gとした場合：

```
外半径 ro = Ds/2
歯先半径 rt = Dr/2+g
ヨーク内半径 ry = 0.85 ro
歯外端 = 0.88 ro
コイル内端 = rt+(ry−rt)×0.04/0.21
コイル外端 = rt+(ry−rt)×0.18/0.21
```

歯半幅、コイル接線寸法、ロータと磁石の元寸法は初期値×roで生成し、5.2の調整を適用する。軸穴は入力径の半分。

**シミュレーション画面の空隙変更は歯先を固定してロータを変更する。一方、標準形状タブは入力したロータ径と空隙から歯先を決める。** 磁石厚さ固定でギャップだけを変える比較機能ではない。

## 6. 材料・巻線・電流仕様

鉄心はロータ・固定子で共通の比透磁率を用いる。空気とコイルはμr=1。磁石は初期μr=1.05、残留磁束密度基準1。鉄心の初期μr=800。線形・等方材料とする。

磁石kの着磁方向はθm+2πk/Pの一定ベクトルで、大きさに(−1)^kを掛ける。k=0が外向きN。局所的な放射状着磁ではない。

自動巻線は歯の電気角を60°の符号付き相帯に割り当てる。相帯境界の同値は角度増加側に割り当てる。0～5相帯の対応はU+、W−、V+、U−、W+、V−。相ごとの歯数が同数で、符号を含む基本波合成ベクトルが120°対称、非ゼロであることを検査する。任意巻線の最適化や手動巻線編集は未実装。

各歯の+v側に `Jz=巻方向符号×相電流×current_density`、−v側には逆符号を与える。初期8P12SではUVWを4回繰り返し、巻方向はすべて+。δはU相合成基本波ベクトルの偏角。

方向符号dは正転+1、逆転−1とする。

```
φ = pθm−δ+d(π/2+β)
iU = I cos φ
iV = I cos(φ−2π/3)
iW = I cos(φ−4π/3)
```

正弦波ではid=−I sinβ、iq=d I cosβ。六ステップは余弦参照の最大相に+I、最小相に−I、残り0を与え、同値は最初のインデックスを採用する。六ステップのdq表示は瞬時電流をPark変換した値で、上記正弦波の関係を流用しない。

正のβは両回転方向で負のidを増やす。永久磁石の残留磁束密度を小さくする処理ではなく、対抗する電流磁界を与える。電圧制限に応じた弱め界磁制御は未実装。

## 7. 磁界計算・境界仕様

### 7.1 方程式

```
B = (∂Az/∂y, −∂Az/∂x)
H = (B−Brem)/μr

∫Ω (1/μr)∇w·∇Az dΩ
 = ∫Ω Jz w dΩ
 + ∫Ω (1/μr)(Brem,x ∂w/∂y−Brem,y ∂w/∂x) dΩ
```

wは試験関数。μ₀等を吸収した無次元方程式を、一次三角形要素で離散化する。材料・励磁源は要素重心で判定する。形状境界を拘束したメッシュを使う。各要素内のBは一定。

### 7.2 メッシュ

Triangleの境界拘束・品質オプション `pq20Q` を使用する。内部点は固定子外半径の±1.06倍の格子に配置し、境界近傍の過近接点を除く。近傍境界をspacing程度で分割し、外側を粗くする。空隙に `min(spacing,air_gap/3)` 間隔のリング点を追加する。点数は形状・角度・間隔に依存し固定ではない。

計算領域は±boundaryの正方形、全外周でAz=0。外側境界変更時に内部の設定spacingを連動して粗くしない。

### 7.3 解法と重ね合わせ

疎行列の内点系をSciPyのLU分解で解く。同じ材料行列に対してPM基底、U−W基底、V−W基底の3解を得る。

```
Az,both = Az,PM + iU Az,U−W + iV Az,V−W
```

「永久磁石のみ」はPM基底のみ、「固定子電流のみ」は電流基底のみを選ぶ。**いずれも磁石・鉄心領域の透磁率と形状は維持する。固定子電流のみでも磁石を完全な空気には置換しない。**

材料分布が変化するので異なるロータ角の行列は流用しない。キャッシュにある同一全パラメータ・同一角度の解は再利用する。相対残差は3基底の内点系残差ノルム／右辺ノルムで、物理精度の保証ではない。

## 8. 後処理・可視化

### 8.1 磁力線・歯Br

磁力線はAz等値線。±0.00001、0.00002、0.00005、0.0001、0.0002、0.0005、0.001、0.002、0.004、および0.008から0.008刻みで0.30以下の固定レベルを使う。解の範囲外のレベルは除外する。不等間隔なので本数・密度をBの定量尺度としない。

通常表示は±1.22×固定子外半径。「計算領域全体」は±boundary。半径による磁力線マスクはなく、窓外の線は表示窓で切れる。物理的に磁束が終わる意味ではない。

各歯のBrは、rt=tooth_inner、ry=yoke_inner、s=min(1,12/S)として：

```
断面u = rt+(ry−rt)×[0.03,0.05,0.07]/0.21
半幅v₀ = tooth_half_width×(0.05/0.065)×s
断面平均Br = [Az(u,+v₀)−Az(u,−v₀)]/(2v₀)
歯Br = 3断面の平均
```

Azは一次要素内の線形補間値を使用。初期モデルではu=0.67,0.69,0.71、v₀=0.05。矢印は径方向、外向き正、長さ0.18×|Br|。全フレーム共通倍率で、自動最大値正規化や非ゼロの最短長を設定しない。

Br矢印は磁束Φでも力でもない。外向き＝反発、内向き＝吸引とは解釈しない。局所的な磁力線の疎密と巻線鎖交磁束は異なる。

### 8.2 無次元トルク

共通空隙の30%、50%、70%位置の半径を評価円とする。

```
rj = tooth_inner−air_gap+[0.3,0.5,0.7]×air_gap
Tj* = ∫₀²π rj² Br(rj,θ) Bθ(rj,θ) dθ
```

1円4096点、角度中点の等間隔和で積分する。元FEM要素のBを使用し、歯Brや表示用点列は使用しない。表示T*は3円の算術平均、範囲は最小～最大。正は囲まれたロータに加わる反時計回りトルク。

評価円間の差は感度指標で、誤差限界・信頼区間ではない。トルクは磁界の二次量なので両励磁のトルクは単独励磁トルクの和にならない。PMのみの小値をゼロに補正・差し引きしない。

### 8.3 トルク履歴・軸

機械角を0～360°へ正規化し小数6桁に丸めて位置キーにする。同じ位置は上書き。最大720位置で、超過時は最初に登録された位置を削除する。

全モデルパラメータ、電流振幅、β、方向、通電方式、励磁源の組を履歴条件とし、記録時に条件が変われば旧点列を削除する。配色・表示切替では既存点列を保持する。クリア後の再描画・記録では現在位置から再開し得る。履歴はメモリ内のみで、終了後には残らない。

計算済み点を表示し、機械角差4.01°以下の隣接点だけ線で結ぶ。未計算位置の穴や360°の端を跨ぐ線は生成しない。現在位置は黄色、各点の縦棒は3円の範囲。

横軸は機械角または電気角pθm。電気角を360°で折り返さない。横軸自動範囲は機械1回転分、縦軸自動は保持点とゼロ線に合わせる。手動範囲は有限数かつ最小<最大で検査し、フレーム更新でも保つ。軸は線形のみ。軸設定は表示を変えるだけで、計算・保持点数を変えない。

## 9. 状態管理・非同期処理

FEM・キャッシュを所有するQObjectをQThreadへ移動し、GUIから要求番号・パラメータ・角度を送る。計算中の追加要求は即時投入せず、完了時に最新パラメータ・角度と照合する。不一致の結果は採用せず、最新条件を要求する。

計算待ちでは直前に完了した形状・磁界・トルクを示す。操作部の要求値と一致していない場合があるため、図の角度・モデル表示を計算結果の条件とする。ワーカースレッドはFEMを担当し、描画・後処理はGUI側で実施する。一定fpsや完全な無停止操作を保証しない。

キャッシュは容量16のLRUで、キーは不変Parametersと要求角度。ディスクキャッシュ、角度補間、バックグラウンド全周事前計算は未実装。ウィンドウ終了時はワーカースレッドの終了を待つ。

|tooth_inner|0.64|歯内端u|

値は有限数でboolean不可。極数・スロット数は整数型必須。未知項目・欠落項目は拒否する。形状はこのパラメータから再生成し、輪郭の頂点やメッシュそのものは保存しない。基準値は5.2の調整を受けるため、最終磁石寸法と同義ではない。

主な追加検査は以下。

```
0.4 ≤ yoke_outer ≤ 2
0 < shaft_radius < tooth_inner−air_gap < tooth_inner < yoke_inner < yoke_outer
tooth_inner < coil_inner < coil_outer < yoke_inner < tooth_outer < yoke_outer
0 < tooth_half_width < coil_v_inner < coil_v_outer
0 < magnet_height ≤ magnet_half_width, apothem > 0
0.008 yoke_outer ≤ spacing ≤ 0.06 yoke_outer
1.5 yoke_outer ≤ boundary ≤ 6 yoke_outer
```

材料値は4.2の範囲。巻線対称性を検査する。生成領域が有効・空でない単一Polygonで計算領域内に収まり、異なる材料領域の重複面積が `1e−10×yoke_outer²` を超えないことを検査する。汎用任意形状の全回転角衝突検査ではない。

サンプルはリポジトリの `examples/8p12s.json`。シミュレーション状態（現在角度・電流・履歴・軸範囲・テーマ）はJSONに含まない。

### 10.2 トルクCSV

UTF-8 BOM付き、カンマ区切り、ヘッダー1行、機械角昇順。保存時点の全保持点を対象とし、軸範囲外の点も保存する。未計算点、リセット済み・容量超過で消えた点は含まない。空履歴ではファイルを作らずエラー表示する。

列順と内容：

|列名|内容|

|electrical_angle_deg|極対数×機械角deg、折り返しなし|
|plot_x|選択横軸の値|
|plot_x_axis|`mechanical` / `electrical`|
|torque_mean_dimensionless|3円のT*平均|
|torque_min_dimensionless|3円の最小T*|

## 11. エラー処理・運用制限

|状況|処理|
|---|---|
|非対応極数・巻線、寸法矛盾|適用／生成を拒否し理由を表示|
|JSON形式不正、未知版、読込I/O失敗|読込を拒否し現在のシミュレーションモデルを保持|
|生成失敗|直前の有効プレビューを保持し、生成済みと扱わない|
|JSON／CSV書込失敗|保存失敗を表示。正常保存と扱わない|
|FEMワーカー例外|再生停止、例外情報を表示|
|不正な軸範囲|軸設定を変更せずエラーを表示|
|空の点列を保存|保存を開始しない|

モデル保存・CSV保存は選択パスへの直接書込で、原子的更新や自動バックアップを提供しない。上書き選択はファイルダイアログに従う。セッション設定の自動保存、Undo、計算途中の強制中断、性能上限の保証はない。

## 14. 未実装事項・将来拡張

現行は線形二次元モデルで、磁気飽和、B–H曲線、ヒステリシス、渦電流、端部効果、PWM、回路連成、逆起電力、機械運動、速度制御、負荷トルク連成を含まない。鎖交磁束、Ld/Lq、TN特性、SIトルク、信頼できる微小コギングトルクの定量化は未実装。

形状読込は標準パラメータJSONのみ。任意ポリゴン、DXF/STEP、個別材料領域・着磁方向・巻線の自由定義は未実装。拡張時は形式・版を区別し、輪郭、移動領域、材料、磁化、巻線、後処理位置の定義を追加する。

SI化する場合は基準長L₀ [m]、基準磁束密度B₀ [T]、積厚l [m]などを明示し、次の換算を実装する。

```
xSI = L₀ x*             BSI = B₀ B*
Az,SI = B₀ L₀ Az*       JSI = B₀/(μ₀ L₀) J*
HSI = B₀/μ₀ H*          TSI = B₀² L₀² l/μ₀ × T*
```

巻線電流・鎖交磁束には巻数・導体断面・占積率・積厚を別途扱う。SI換算式の記載は換算機能の実装を意味しない。実機比較へ進む前にメッシュ、積分点、評価円、境界、全評価条件の収束と材料モデルの妥当性を確認する。
