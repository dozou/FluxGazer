# FluxGazer — Electric Motor Simulation

FluxGazer（フラックスゲイザー）は、回転型モーターの磁界と特性を可視化するPythonシミュレータです。現行版はSPMモーターの二次元・線形静磁界解析と無次元トルクの参考表示に対応し、初期モデルは8極12スロットです。

内部Pythonパッケージ名は `motor_sim`、既存JSONの形式識別子は `motor_sim.standard_spm` を継続使用します。名称変更前の定義ファイルと起動コマンドはそのまま利用できます。

現行の機能・計算式・画面・JSON/CSV形式をまとめた仕様書は [doc/specification.md](doc/specification.md) を参照してください。

## グラフ点列のCSV保存・軸設定

「トルク点列をCSV保存…」で現在の履歴を保存できます。Excelでも開きやすいUTF-8 BOM付きCSVで、機械角順に出力します。表示範囲外も含む保存時点の全保持点が対象です。機械角・電気角・選択横軸値、無次元トルク平均／最小／最大、3本の評価円半径と個別トルク、電流振幅・進角・方向・励磁方式・励磁源、モデルの全パラメータを各行に保存します。履歴リセット前の点や未計算点は含みません。Nmへの換算は行いません。

「トルクグラフの軸設定…」で横軸を機械角／電気角に切り替え、横軸・縦軸それぞれの最小／最大を指定できます。電気角は極対数×機械角で、360°で折り返しません。横軸自動は機械1回転分（電気角なら極対数×360°）、縦軸自動は保持点とゼロ線に合わせます。手動範囲はフレーム更新・表示切替でも保持します。軸変更は表示だけで、磁界計算や保存する点列を変更しません。最大値は最小値より大きい必要があり、不正な範囲は適用しません。

## 配色とトルクグラフ

シミュレーション画面上部の「ダークモード」で明暗を切り替えます。起動時はOSから取得した配色を初期選択し、その後はこのチェックで変更できます。両タブの背景・文字・グラフ軸と、磁力線・鉄心・磁石の色をまとめて変更します。

磁界図の下に、横軸＝機械角0～360°、縦軸＝無次元トルクT*のグラフを表示します。再生または角度変更で計算済み位置を記録し、現在位置を黄色で示します。縦棒は評価円3本の最小～最大で、誤差保証ではありません。未計算角度を埋めず、近接する計算点だけを線で結びます。一周の自動事前計算や時間・rpmグラフではありません。

形状・材料・メッシュ・電流振幅・進角・通電方式・回転方向・励磁源のいずれかを変更すると、異なる条件の履歴を消して現在の条件から記録します。配色と磁力線／矢印の表示切替では履歴を保ちます。履歴は最大720位置、同じ角度は上書きし、「トルクグラフをクリア」で消せます。グラフとの境界をドラッグすると磁界図との高さ配分を変更できます。

## 同期トルク表示（無次元・参考値）

シミュレーション画面の「ロータトルク T*」は、表示中の角度・電流・励磁源と同じFEM解から求めます。正は反時計回りです。機械運動や負荷トルクとの連成はしません。計算中は磁界とともに直前に完了したモデルの値を保持します。

`T* = ∫₀²π r*² Br* Bθ* dθ` を空隙内の3本の円（空隙の30%、50%、70%位置）で積分します。各円4096点で元の一次三角形要素のBを使用し、表示用の間引きデータや歯Br矢印は使いません。表示値は3円の平均、併記範囲は3円の最小～最大です。この範囲は評価円依存性の指標で、誤差保証や信頼区間ではありません。

「永久磁石のみ」「固定子電流のみ」を選ぶと、その励磁条件のトルクになります。両励磁のトルクには磁界の交差項があるため、単独トルク同士の和とは一致しません。PMのみの微小値をゼロに丸めたり、計算結果から差し引く補正はしていません。

SI換算は `T [Nm] = B₀² L₀² l / μ₀ × T*` です。B₀、L₀、実機の積厚lが未設定なので、現在の表示はNmでも単位積厚あたりのSIトルクでもありません。実機予測・コギングトルクの定量評価には使えません。

`python validate_torque.py` でメッシュ・評価円・外側境界の感度を再計算し、`artifacts/torque-validation.json` に保存します。初期8P12S、機械角0.137 rad、正弦波I=1、β=0、両励磁での今回の結果：

|点間隔|境界半幅|T*（3円平均）|3円の最大−最小|
|---|---:|---:|---:|
|0.025|3|0.080528|0.003420|
|0.018|3|0.082268|0.000141|
|0.012|3|0.081938|0.000687|
|0.018|2|0.082298|0.000020|
|0.018|4|0.082318|0.000119|

細分化で評価円差が単調減少するわけではなく、全角度での収束は未確認です。PM単独の平均値は点間隔0.025/0.018/0.012で約−0.000724/+0.000389/−0.000332と符号も変わります。現状、その微小値を物理的なコギングトルクと断定できません。正逆の符号、磁界2倍で応力トルク4倍、ゼロ磁界、積分点数倍増、GUIの同期をテストしています。

## 標準形状・物性定義タブとファイル読込

1. `main.py` を起動し「標準形状・物性定義」タブを開きます。
2. 極数・スロット数、固定子外径、ロータ包絡外径、軸穴径、空隙を設定します。鉄心／磁石の比透磁率、残留磁束密度、電流密度基準、メッシュ点間隔、外側境界も編集できます。
3. 「生成・プレビュー」で形状を確認し、「定義ファイル出力…」でJSONを保存します。未生成の編集がある場合、出力前に再生成・検査します。失敗した場合は出力せず、プレビューは直前の有効な形状を保ちます。
4. 「シミュレーション」タブの「定義ファイル読込…」でJSONを選びます。材料・メッシュ・励磁基底を再構築します。「シミュレーションへ適用」ではファイルを介さず生成済みモデルを渡せます。

サンプルは `examples/8p12s.json` です。定義タブの「定義ファイルを開く…」で再編集できます。定義タブの編集中モデルとシミュレーション中のモデルは独立しています。シミュレーション側で極数・空隙を変更しても、保存ファイルや定義タブは書き換えません。

全寸法は共通の基準長L₀に対する**無次元値**です。固定子外径を変えてもL₀を自動で変えません。ロータ径は磁石と鉄心を含む回転包絡径、歯先径は「ロータ径＋2×空隙」です。固定子外径と空隙を変えた際にロータ径が暗黙に変わらないよう、標準生成では歯先位置をこの式で決めます。既存シミュレーション画面の空隙だけの変更は、従来どおり歯先を保ちロータを変更します。

標準生成ではヨーク内半径を外半径の0.85倍、歯外端を0.88倍とし、コイル径方向位置を歯先～ヨーク間に比例配置します。歯・コイルの接線幅と磁石の元寸法も固定子外半径に比例します。Brの3測定断面・測定幅、矢印の始点、表示窓、メッシュの内部／外部領域はモデル寸法に追従します。矢印のBr→長さの倍率0.18は変更しません。

JSONの形式は `motor_sim.standard_spm`、バージョン1です。`units`、巻線生成規約、全パラメータを保存し、未知の形式・単位・欠落項目・非数値・無限大・寸法の矛盾・材料領域の重複を拒否します。磁石の着磁方向はこの形式では極中心方向、N/S交互です。計算中の読込でも旧設定の結果を新設定として採用しません。

今回の読込対象は**標準形状のパラメータ定義JSON**です。任意のポリゴンやDXF/STEPの読込は未実装です。将来は別の形式識別子・バージョンで領域輪郭、材料割当、着磁方向、巻線を持つインポータを追加できます。今回のファイルをCAD形式やSIモデルとしては扱いません。読込直後に編集せず再出力する場合は、読み込んだ全パラメータを保持します。定義タブで数値を編集して再生成すると標準比率に基づく形状へ更新します。

実装は `definition.py`（生成・検査・JSON入出力）、`editor.py`（定義タブ）、`drawing.py`（共通輪郭描画）に分離しています。ファイル往復の形状一致、寸法変更モデルのFEM、異常ファイル拒否、GUIでの生成・保存・読込をテストしています。

## エアギャップの変更

画面上部の「エアギャップ / L₀」を変更して「適用」を押します。初期値0.050、範囲0.010～0.200で、固定子外半径L₀=1の無次元値です。mmではありません。

指定量は **歯先の内接円半径 − ロータ鉄心・磁石全体の最大半径** です。ロータが一回転する間の最小クリアランスを表し、歯と磁石の間の局所距離は角度によって大きくなります。磁石頂点より多角形鉄心の角が外側にある構成では、その角からのクリアランスです。

固定子・巻線・軸穴半径を保ち、ロータ外形と磁石の幅・厚さを一様拡大縮小して指定値を実現します。磁石厚さ固定でロータ径だけを変える操作ではないため、磁界変化には磁石寸法の変化も含まれます。8P12S・空隙0.050では当初の寸法を保ちます。他の極数でも指定空隙が優先されます。

形状と材料境界を再生成して再計算し、キャッシュも空隙別です。狭い空隙には間隔 `min(spacing,air_gap/3)` の局所リング状メッシュ点を追加します。これだけで磁界・トルク精度が保証されるわけではありません。下記の感度表はこの局所細分化を追加する前の参考記録で、現在の結果は `validate.py` で再生成してください。

## 極数・スロット数の変更

画面上部の「極数」「スロット数」を選び「適用」を押してください。初期値は8極12スロットです。極数は4～24の偶数、スロット数は6～36の3の倍数から選択できます。4P6S、8P12S、10P12S、12P18S、16P24S、24P36Sを磁界計算で検証しています。

巻線は歯の電気角に最も近い符号付き60°相帯で自動設定し、歯名のU+/V−などで相と巻方向を表示します。対称三相にならない組合せは適用を拒否し、直前のモデルを保ちます。これは任意巻線設計の最適化ではありません。8P12Sでは従来のUVW繰り返し・同方向巻線を再現します。

極対数pに合わせてθe=pθmへ変更します。自動巻線のU相基本波軸のずれδ（例：10P12Sでは15°）を補正し、正転φ=θe−δ+90°+β、逆転φ=θe−δ−(90°+β)とします。dqも同じ軸で算出します。8P12Sはδ=0です。

形状の重なりを防ぐため、歯・コイルの接線幅とBr測定幅は `min(1,12/slots)` 倍、磁石半幅・厚さは `min(1,tan(π/poles)/tan(π/8))` 倍に自動調整します。低極数でロータの角が歯に近づく場合、アポセムを `min(0.47,(0.64−0.025)cos(π/poles))` とします。固定子径と径方向の歯・コイル位置は保ちます。寸法固定の極数比較とは異なる仮形状です。

適用時は再生を停止し、材料・メッシュ・励磁基底を再計算します。計算中の旧設定の結果は新設定として表示しません。キャッシュは極数・スロット数を含む全パラメータ別です。以下の8P12Sの寸法説明と感度結果は初期設定についての記述で、他の組合せの精度保証ではありません。

Python / PySide6 / NumPy / SciPy による、無次元・線形の一次三角形FEMです。
永久磁石、鉄心、集中巻線を含む各ロータ位置の静磁界を表示します。
回転は2°ずつの準静的な位置走査で、運動方程式による実回転数ではありません。

このリポジトリでは既存の `.venv` を修復し、依存関係をインストール済みです。
PowerShellでリポジトリに移動して実行します。

```powershell
.\.venv\Scripts\python.exe -m motor_sim
# main.pyからも起動できます（IDEの実行対象にも指定可能）
.\.venv\Scripts\python.exe main.py

.\run.ps1
```

## 操作

機械角、電流振幅0～1.5 p.u.、進角−60～60°、正弦波／六ステップ、正転／逆転、励磁源を操作できます。再生ボタンで位置走査を開始・停止します。磁力線・Br矢印を個別に切り替えられます。歯の値は右の表と歯付近のツールチップで確認できます。

計算はQtワーカースレッドで実行します。計算中は最後に完了した角度の形状と磁界を一緒に保持します。角度変更が続いた場合は最新の要求角に追従します。アニメーション速度は計算・描画時間に依存し、rpm表示はしません。

## 形状と材料

固定子外半径1。環状ヨーク0.85～1、12本の歯は局所u=0.64～0.88、v=±0.065。歯0は+x、反時計回り30°間隔です。ヨークと歯の接合部は同一鉄心に結合し、張り出した歯先はありません。

ロータはアポセム0.47の正八角形、軸穴半径0.15。8個の磁石は平面底部u=0.47、半幅0.16、高さ0.12、頂点u=0.59。円弧半径は `(0.16²+0.12²)/(2×0.12)`。極中心方向に一様着磁し、外向きN/Sを交互に配置します。点ごとの放射状着磁ではありません。

コイルは各歯のu=0.68～0.82、v=0.078～0.12とその反対側。U,V,Wを4回繰り返します。同一歯の+v側を+Jz、−v側を−Jzとする共通規約です。FEM結果で、U正・V/W負のときU歯のBrが外向きになることを確認しています。

比透磁率は鉄800、磁石1.05、空気／コイル1。Br残留値は1。1 p.u.の仮電流密度を無次元5と置きました。実機のアンペアや巻数との対応はまだありません。変更箇所は `motor_sim/geometry.py` の不変データクラス `Parameters` です。

輪郭をポリゴン化し、同じ輪郭を材料分類・境界拘束メッシュ・描画に使います。円弧は弦で近似します。歯とヨークの意図した接合以外の材料の面積重複は検証しています。磁石底面とロータは端点を共有します。

## 方程式と符号

`B = (∂Az/∂y, −∂Az/∂x)`、`H = (B − Br)/μr` とした無次元モデルです。試験関数wに対し、

```
∫ (1/μr) ∇w · ∇Az dΩ
  = ∫ Jz w dΩ + ∫ (1/μr)(Brx ∂w/∂y − Bry ∂w/∂x) dΩ
```

を一次三角形で離散化します。各角度で材料を再構築し、同じ剛性行列で永久磁石、U−W、V−Wの3基底を解きます。平衡三相の電流解は `iU*basisUW+iV*basisVW`。LRUキャッシュは16角度で、角度間・材料境界をまたぐ解の補間はしません。

電気角θe=4θm。正転はφ=θe+90°+β、逆転はφ=θe−(90°+β)。各相は `I cos(φ−[0,120,240]°)`。正弦波では両方向ともid=−I sinβ、iqは正転+I cosβ、逆転−I cosβです。逆転は位置走査の向きと電流のq成分をともに変えます。

六ステップは余弦参照値の最大相+I、最小相−I、残り0。同値時はNumPyの最初のインデックスを採用します。GUIには実際の瞬時電流から計算したPark値を表示し、正弦波のid/iq式を六ステップに流用しません。

## 表示量・境界

12歯のBrはu=0.67,0.69,0.71で `[Az(u,+0.05)−Az(u,−0.05)]/0.10` を取り、3断面平均します。一次要素内のAz補間を用います。外向き正、矢印長は常に `0.18*|Br|`。フレーム正規化や見かけの長さ下限はありません。

磁力線はAz等値線です。微弱な外部磁界を見せるためゼロ近くに細かい固定等値レベルを追加しており、線の本数／密度をそのままBの比較尺度にはできません。正負Azの実線／破線は磁極・力の符号ではありません。

既定の計算領域は正方形±3、外周Az=0。モーター付近の点間隔0.018を維持し、外側を粗くします。既定表示は±1.22で、物理半径によるマスクはありません。「計算領域全体」で外部空気と境界まで表示できます。拡大表示の端で線が切れるのは表示窓によるものです。外周Az=0は遠方境界の近似で、漏れ磁束の実測再現ではありません。

## 解釈と今回の範囲

Br矢印は磁束密度の径方向成分で、磁束Φや力ではありません。外向き＝反発、内向き＝吸引ではありません。径方向の吸引が大きくてもトルクには接線方向の磁気応力が必要です。磁力線の外観からトルク符号を判定しないでください。

進角は負荷トルクとは別の量です。負のidはPMに対抗する電流磁界を作ります。磁石の残留磁束密度を下げる処理はしていません。局所的な線の疎密と鎖交磁束低下は別で、鎖交磁束は今回未算出です。電圧制限を伴う弱め界磁制御ではなく、指定電流による磁界変化です。

磁気飽和、ヒステリシス、渦電流、端部効果、PWM、回路連成、逆起電力、機械運動、速度制御、負荷トルク、実機の定量トルク評価は未実装です。無次元のマクスウェル応力トルクは参考表示しています。

## SI移行と拡張

基準長L₀ [m]、基準磁束密度B₀ [T]を定めた場合：

```
x_SI = L₀ x*             B_SI = B₀ B*
Az_SI = B₀ L₀ Az*       J_SI = B₀/(μ₀ L₀) J*
H_SI = B₀/μ₀ H*
```

コイルの電流密度は巻数・導体断面・占積率から別途設定します。積厚lを用いた磁束／鎖交磁束にはB₀L₀lと巻数が必要です。空隙のマクスウェル応力トルクは `l/μ₀ ∮ r Br Bθ ds` で、基準は `B₀²L₀²l/μ₀`。これらは換算設計の説明で、アプリの数値はT/A/Nmではありません。

将来はB–H曲線、実寸法・積厚・巻数・磁石特性を導入し、鎖交磁束・逆起電力・Ld/Lq・SIトルク評価を追加できます。定量化には空隙の細分化、評価円と外側境界の依存性を全評価条件で検証してください。特にコギングトルクを表示用の粗い値から定量評価しない設計とします。
